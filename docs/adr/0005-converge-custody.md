# ADR-0005: Converge composition and run custody

Status: Proposed. Date: 2026-10-06. Owner: Runtime/bundle maintainer.

## Context

Root bundle availability and helper agents do not prove manager/work-tracker activation.

## Proposal

Compose Converge with a pinned host and project-local specialist guidance; one manager owns each mapped attempt.

## Alternatives

Global bundle replacement; duplicate Studio/native schedulers; guidance-only behavior as manager.

## Rationale

Reuse qualified workflow while preserving native custody and explicit Studio mappings.

## Consequences

Resolve real behaviors/modes/dependencies, worker sessions, contract locks, and cancellation before runtime use.
