# ADR-0001: Repository baseline

Status: Proposed. Date: 2026-10-06. Owner: Application maintainer.

## Context

The local v0.1 source backup and earlier private prototype cover different scopes.

## Proposal

Continue cloudflare-artifacts-studio; use the prototype as a comparison source.

## Alternatives

Continue the private prototype; merge both histories; create a third application.

## Rationale

A runnable app and current user-directed repository provide a concrete baseline.

## Consequences

Port stronger prototype contracts selectively; keep private data and licensing boundaries.
