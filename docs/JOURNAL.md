# Journal and learning conventions

Status: proposed continuity practice. Reuse the existing Amplified Design worksheets rather than copy its reference manual.

Sources at the [pinned knowledge revision](https://github.com/amplifier-chipster6/amplified-design/tree/335abd4f4d79415185d81b5498547c59582f91c6/output/studio-learning-kit):

[capability contract](https://github.com/amplifier-chipster6/amplified-design/blob/335abd4f4d79415185d81b5498547c59582f91c6/output/studio-learning-kit/capability-contract-template.md),
[capability inventory](https://github.com/amplifier-chipster6/amplified-design/blob/335abd4f4d79415185d81b5498547c59582f91c6/output/studio-learning-kit/capability-inventory-template.md), and

Record intent, observed capability, reuse/configure/compose/extend choice, alternatives, tradeoffs, exact evidence, decision authority, unresolved work, and the next bounded experiment. Preserve timelines and supersession; do not rewrite a failed attempt as success.

Use [the local journal template](templates/journal.md) for a small session entry and [handoff template](templates/handoff.md) for continuation. Link canonical specs, ADRs, records, commits, and receipts rather than reproduce them. Private handoffs go to an authorized private destination; public docs contain sanitized references only.

A journal explains why. A structured decision authorizes what. A receipt establishes what actually happened. Memory may derive learning from all three while preserving their distinctions.

When the second website pilot completes, use the transfer worksheet to identify what generalized and what remains Unified-specific. Promotion to shared capability requires evidence, not optimism.
